# DL-002 Database Lineage Contract

## Scope

This contract maps each live table and reporting view to its fill path, grain, source of truth, primary consumers, and empty-table semantics. It is a documentation contract only; it does not change schema, ingestion, migrations, scripts, API behavior, or deployment behavior.

Current database state should be verified with the DL-001 snapshot command and interpreted as diagnostic evidence for that run only, not as a permanent guarantee. In this worktree, `Documentation/Validation/DL-001_DATABASE_SNAPSHOT.md` documents the snapshot output sections and empty/missing-table interpretation, but does not include a captured row-count result. A local read-only attempt to run `scripts/database_snapshot.py` for this ticket timed out with `OperationalError`, so current row counts remain unresolved here.

## Layer Definitions

- Source archive: raw and parsed OeKB source records retained before curation.
- Curated tax facts: normalized securities, tax report headers, tax values, adjustments, distributions, correction links, and tax dictionaries.
- Reference/FX data: ECB FX observations and static reference dictionaries.
- Operational logs: ingestion run and error observability.
- Reporting contracts: SQL views exposed for spreadsheet/BI-style reporting.

## Downstream Consumer Summary

- API tax endpoint: `TAXRPT`, `TAXDAT`, `TAXLIN`, `TAXCAT`.
- Analyst SQL and BI tools: `TAXRPT`, `TAXDAT`, `TAXLIN`, `TAXCAT`, plus `V1_TAXDATPRE` and `V2_TAXDATEUR` for selected pivoted reporting.
- Audit/debugging: `SOURCERPT`, `SOURCERAW`, `SOURCEAGE`, `IMPLOG`, `IMPERR`.
- Currency checks and EUR conversion: `REFEXC`, `V2_TAXDATEUR`.
- Correction and cash-flow analysis: `TAXCOR`, `SECDIV`.

## Unresolved Lineage Questions

- `REFCCY` and `REFCTR` have schema and documentation meaning, but no active seed path or authoritative business source was found in the reviewed code.
- Current row-count and current empty-table classifications for this local database are unresolved because the DL-001 document in the repository is a snapshot specification, not a captured output, and the local snapshot command failed with `OperationalError`.
- `REFEXC` exact-date semantics are documented here as current behavior; any future nearest-prior-date FX policy would change the `V2_TAXDATEUR` contract.
